# Business Insights Dashboard

## Overview
The Business Insights Dashboard is a simple yet interactive data visualization web application designed to represent real-world business metrics in a visual and intuitive way.  
It helps users understand trends, comparisons, and distributions using charts instead of raw numbers.This dashboard simulates how sales teams, marketing teams, or product analysts monitor key performance indicators (KPIs) using visual analytics.

---

## Purpose of the Project
The main goal of this project is to:
- Demonstrate the use of data visualization in decision-making
- Present business data in a clear and engaging format
- Practice building interactive dashboards using core web technologies

---

## Key Features
- Interactive bar, line, and pie charts
- Dark mode for better viewing experience
- Ability to highlight a selected chart
- Toggle option to show or hide all charts
- Download individual charts as images
- Clean card-based layout inspired by real-world dashboards

---

## Technologies Used
- HTML5 for structure
- CSS3 for layout, styling, and dark mode
- JavaScript for interactivity and logic
- Chart.js for rendering charts

---

## Dashboard Components
- **Monthly Sales Chart**  
  Displays monthly revenue trends to analyze business performance.
  
- **Website Traffic Chart**  
  Shows how user visits change over time.

- **Device Usage Chart**  
  Represents how users access the platform (Desktop, Tablet, Mobile).

---

## How to Run the Project
1. Download or clone the project files.
2. Make sure all files (`index.html`, `styles.css`, `script.js`) are in the same folder.
3. Open `index.html` in any modern web browser.
4. No server or installation is required.
